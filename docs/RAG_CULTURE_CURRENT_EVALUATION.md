## 6. 基线暴露出的主要问题

1. **无答案保护。** 6 道明确缺少结构化资料的问题均被资料充分性闸门拦截，没有把相似片段交给生成模型。
2. **对话上下文。** 评测集中的上下文追问均能继承最近用户话题，并进入预期案例或召回预期片段。
3. **错别字会破坏案例路由。** 错别字题中未通过的是：无；当前配置会先记录并修正审核过的领域错字，再做案例别名匹配。
4. **终局意图。** 本轮题集中的终局表达已全部正确识别，同时避免把“企业后来怎么解释”误判成终局问题。
5. **案例路由。** 本轮固定试卷的案例与一般文化问题均进入正确轨道；后续新增案例仍须补充相似事件和错别字负例。
6. **一般文化问题存在语义错配。** 回答用途过滤已区分文化与薪酬福利、经营表现与文化复制、顾客投诉奖与员工委屈奖，并拦截未指定案例的企业自行送检终局问题；这只覆盖已审核用途，不等于能够自动判断任意问题的资料充分性。

以上是当前算法的真实能力快照，不在本轮通过修改 Query 改写、别名或排序来美化分数。
