## 1. 本轮完成了什么

R4 不再只停留在路线图文字中，已经接入网站生成回答前的系统提示词。

一般文化问题按以下理解顺序自然组织：

```text
简单说
→ 具体来看
→ 为什么这么做
→ 还要分清
```

热点事件按以下理解顺序自然组织：

```text
这件事现在知道什么
→ 企业当时怎么处理
→ 后来有没有明确结论
→ 这件事让我们观察什么
```

资料不足时单独采用：

```text
简单说
→ 目前能确认什么
→ 为什么还不能下结论
→ 还缺什么信息
```

三种方式都明确要求：这些是理解顺序，不是必须逐字显示的机械标题；短回答可以自然合并，但不能省略会改变结论的重要限制。

- `evaluation/rag-culture-r4-contract-evaluation.json`：保存本次可复现结果。

## 4. 18/18 不代表什么

自动检查没有调用 DeepSeek，因此 18/18 只证明：系统已经为 18 道代表题准备了正确的资料范围、事件轨道和 R4 回答规则。

它不证明模型实际生成的每一句话都自然、通俗或完全遵守边界。真实回答仍要逐题检查：

1. 第一段是否直接回答；
2. 是否只选一至三个相关例子；
3. 是否把文化逻辑讲成人与经营的关系；
4. 是否自然保留归因、时间、适用范围和不同观点；
5. 是否覆盖原题的 `expectedAnswerPoints`；
6. 是否避开原题的 `forbiddenClaims`；
7. 热点事件是否把企业回应、媒体记录、监管结论和司法结论分开。
