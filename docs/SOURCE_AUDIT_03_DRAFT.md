## 结论先行

本轮最适合优先审计的是 **V3-1“茶叶反馈事件”** 与 **V3-2“鲜鸡蛋视频争议”**。二者都可支撑“面对网络反馈时，企业公开表示采取了哪些调查或处置动作”的问答；但都**不能**直接证明最初短视频指控本身为真，也不应概括为“抖音舆论普遍支持/反对胖东来”。

1. 找到并核验 V3-1、V3-2 所涉胖东来官方抖音账号原帖：账号主体、视频/公告 ID、发布时间、当前可访问性、截图或网页存档方式。  
2. 核对 V3-1 是否存在后续“情况说明（二）”或最终调查/处理报告；若找不到，明确标记“仅初步处置，禁止写成最终结论”。  
3. 核对 V3-2 是否有市场监管部门的最终公开结论；若没有，维持企业检测结果的归因式表述。  
4. 对 V3-3、V3-4 确认是否保持 limited；不得为满足数量而升等级。  
5. 审计完成后，在本文件追加“Grok 审计结论”和“建议用户批准条目”。

## 用户批准前的入库规则

- 优先只考虑 V3-1、V3-2，且采用 **L2 + 归因回答**；补到官方原帖后再形成 L1+L2 证据对。  
- V3-3 即使入库也应限制为“网络争议/司法报道背景”，禁止用于压制正常消费者投诉。  
- V3-4 本轮不入库。  
- 不将抖音评论、热搜排名、点赞数作为事实依据；若以后做舆情观察，应建立独立 L4 数据集与明确采样方法。
