# RAG 文化片段标注 V1

**完成日期：** 2026-08-02

**标注范围：** 正式知识库现有 30 份资料、135 个检索片段、6 个案例

**版本：** `culture-v1`

## 1. 目的

这次标注把原来只有标题、正文和主题词的片段，补成可支持“做法—机制—价值—边界”理解的文化知识片段。字段只供知识库构建、检索、评测和回答组织使用，不在普通用户界面直接展示。

标注属于编辑性解释，不是来源原文，也不能提高来源本身的证据等级。尤其是 `valueMeaning`，统一使用“可用于理解”或“可用于检验”的克制表述，不能被改写成企业事实或最终结论。

## 2. 字段

每个片段新增 `culture`：

| 字段 | 含义 |
|---|---|
| `annotationVersion` | 固定为 `culture-v1` |
| `relevance` | `direct` 直接做法、`supporting` 辅助理解、`boundary` 边界/反面约束、`context_only` 纯背景 |
| `cultureTheme` | 关联的 C1～C6 文化主线；纯背景资料允许为空数组 |
| `practice` | 来源中可以观察到的具体做法；没有依据时为 `null` |
| `mechanism` | 做法的流程、制度或运行方式；没有依据时为 `null` |
| `valueMeaning` | 该片段可能帮助理解或检验的价值取向；不是事实断言 |
| `stakeholders` | 员工、顾客、供应商、管理者、公众、监管与司法、同行企业 |
| `tension` | 现实限制、不同观点、时效、来源或结论边界 |
| `effectiveAt` | 片段对应时期、来源发布日期；无发布日期时使用核验日期 |

六条主线沿用文化知识地图：

- C1：员工的尊严、自由与生活
- C2：信任、一线授权与责任
- C3：顾客关系与真诚服务
- C4：商品、品质与供应链
- C5：利润、规模与经营节制
- C6：争议中的文化检验

## 3. 标注结果

135 个片段全部带有 `culture-v1` 结构：

| 维度 | 数量 |
|---|---:|
| 直接材料 `direct` | 46 |
| 辅助材料 `supporting` | 30 |
| 边界材料 `boundary` | 55 |
| 纯背景 `context_only` | 4 |
| 有具体做法 | 62 |
| 有运行机制 | 35 |
| 有解释性价值含义 | 76 |
| 有现实张力/边界 | 55 |
| 有对应时间 | 135 |

文化主线允许一条资料同时关联多个主题，因此下列数量不能相加作为片段总数：

| 主线 | 片段数 |
|---|---:|
| C1 | 60 |
| C2 | 52 |
| C3 | 62 |
| C4 | 48 |
| C5 | 18 |
| C6 | 56 |

4 个 `context_only` 片段是图书目录/元信息和企业简介。它们仍已完成关联级别、利益相关者与时间标注，但不强行挂到文化主线，也不生成文化含义。

## 4. 安全边界

1. 所有具体案例片段都带 C6，但仍受原有 `caseId`、`claimType` 和 `finality` 约束。
2. 标注为某一文化主线，不代表该片段能证明整个企业文化真实有效。
3. `boundary` 必须填写 `tension`；没有最终材料时，标注不能产生终局话术。
4. 没有证据支持的做法、机制或含义保留 `null`，不为追求字段完整而补写。
5. 新片段不得自动套用本次批量迁移规则；应在来源审核后单独标注。

## 5. 技术落实

- 一次性迁移脚本：`pangdonglai_project/site/scripts/annotate-culture-v1.mjs`
- 正式片段：`pangdonglai_project/knowledge/chunks/*.jsonl`
- 构建校验：`pangdonglai_project/site/scripts/build-knowledge.mjs`
- 生成索引：`pangdonglai_project/knowledge/compiled/knowledge-base.json`

构建脚本现在会拒绝缺少标注、使用未知主线/利益相关者、边界材料没有张力说明，或把文化含义写成无保留断言的片段。

本次字段落库后已用同一套 54 题完成两类 BM25 对照实验。非案例 `culture-v1` 字段直接拼接由控制组 39/54 降至 38/54，禁用片段隔离由 51/54 降至 50/54；Query 文化主线识别达到 54/54，但对原候选做 3%～20% 小权重重排始终保持 39/54，没有新增通过。因此两种实验都不启用到正式检索。详见 `docs/RAG_CULTURE_BM25_CULTURE_V1_EXPERIMENT.md` 与 `docs/RAG_CULTURE_BM25_THEME_RERANK_EXPERIMENT.md`。网页未重新部署；下一步进入错别字和同义表达的 Query 改写。
