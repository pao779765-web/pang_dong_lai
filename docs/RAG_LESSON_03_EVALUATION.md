# RAG 第三课：资料库扩充前，先学会检验检索

## 本课目标

你已经完成了一个能运行的链路：

```text
用户问题 → BM25 → 已审核资料 → DeepSeek → 流式回答与来源
```

下一步不是立刻换向量数据库，而是回答一个更基础的问题：**BM25 找到的资料，真的适合回答用户的问题吗？**

本课不改网站代码、不调用 DeepSeek、不自动把新来源写入 `knowledge-base.json`。

---

## 1. 先认识当前资料库的边界

当前 `knowledge-base.json` 只有一份已批准资料：官方门店信息页。它包含三个片段：

| 片段 ID | 可支持的问题 |
| --- | --- |
| `store-directory-hours` | 营业时间、周二闭店、例外门店 |
| `store-directory-xuchang-yuzhou` | 许昌、禹州的门店地址 |
| `store-directory-xinxiang` | 新乡门店地址 |

因此，下面两句话必须分清：

- “新乡三胖在哪里？”——资料库**应该能回答**。
- “胖东来的企业文化为什么强调自由与爱？”——资料库**目前不该硬答**。

第二类问题回答不好，不等于 BM25 坏了；很可能只是资料库没有对应证据。

---

## 2. 三种失败，不能混为一谈

| 现象 | 真正的问题 | 下一步应该做什么 |
| --- | --- | --- |
| 根本没有相关资料 | 资料缺口 | 审计并补充新来源 |
| 有相关资料，但 BM25 排在后面 | 检索排序问题 | 调整片段、标题、词汇或检索算法 |
| 找到了资料，但模型回答超出资料 | 生成约束问题 | 调整系统提示词、引用和回答规则 |

这就是 RAG 调试最重要的顺序：**先看资料，再看检索，最后看模型。**

---

## 3. 建立第一份检索测试集

测试问题不需要立刻发给 DeepSeek。先看 BM25 是否应该把正确片段排进前 3 名。

| # | 测试问题 | 预期结果 | 正确片段 / 行为 |
| --- | --- | --- | --- |
| 1 | 胖东来周二是否闭店？ | 应回答 | `store-directory-hours` |
| 2 | 哪些门店周二不闭店？ | 应回答 | `store-directory-hours` |
| 3 | 新乡三胖在哪里？ | 应回答 | `store-directory-xinxiang` |
| 4 | 许昌有哪些门店？ | 应回答 | `store-directory-xuchang-yuzhou` |
| 5 | 禹州店地址在哪里？ | 应回答 | `store-directory-xuchang-yuzhou` |
| 6 | 周五几点关门？ | 应回答，但提醒以官网最新页面为准 | `store-directory-hours` |
| 7 | 胖东来有多少家全国门店？ | 不应硬答 | 资料不足 |
| 8 | 胖东来的薪资福利制度是什么？ | 不应硬答 | 资料不足 |
| 9 | “自由与爱”具体意味着什么？ | 不应硬答 | 资料不足 |
| 10 | 胖东来为什么不盲目扩张？ | 不应硬答 | 资料不足 |

其中 1–6 是“正例”，检验能否找到证据；7–10 是“负例”，检验系统会不会胡乱套用无关资料。

---

## 4. 手工判分方法

每个问题只记三项：

| 项目 | 判断标准 |
| --- | --- |
| 检索是否正确 | 正确片段是否进入前 3 名 |
| 回答是否克制 | 没有资料时是否明确说资料不足 |
| 来源是否匹配 | 回答末尾是否只展示真正使用的来源 |

可以用下面的表格做记录：

| 问题 | 前 3 个检索片段 | 是否正确 | 问题属于哪一类 |
| --- | --- | --- | --- |
| 新乡三胖在哪里？ | 待填写 | 是 / 否 | 排序问题 / 无问题 |
| 自由与爱是什么意思？ | 待填写 | 是 / 否 | 资料缺口 / 生成约束 |

判断时不要只看回答“像不像对的”；要看它有没有证据、证据是否真的支持回答。

---

## 5. 下一份资料该补什么？

目前最值得补的是一份**带明确来源属性的企业公开表述或权威媒体访谈**，用来支持“企业如何自述理念”的问题。

已有审计中，下面这条仍是候选，尚未批准入库：

```text
《用真诚换取信任，用信任赢得市场——胖东来商贸集团董事长于东来访谈》
https://cpc.people.com.cn/n1/2025/0819/c64387-40545235.html
```

如果未来批准它，写入资料卡时必须遵守：

1. 标记为 `media`，而不是 `official`；
2. 写“报道记录了受访者的公开表述”，不把受访者观点写成已独立核验事实；
3. 只保存自己的简短摘要、主题与来源链接，不复制整篇报道；
4. 只让它回答“该访谈中如何表述”的问题，不让它单独证明薪资、经营数据或制度细节。

---

## 6. 你现在要掌握的一句话

> 资料不够时，正确的 RAG 不是更努力地回答，而是更明确地说“当前资料不足”。

当你能稳定区分“资料缺口”和“检索错误”，再进入向量检索或混合检索，才会真正知道新技术解决了什么问题。
