| 选项 | 说明 |

**Grok 默认建议：C 优先；若你明确要「体验向」问答素材，则选 A（limited），不要选「当硬事实 approved」。**

### 风险

1. **等级最低（L4）**：协议明确社交不能单独证明争议事实或终局结论。  
2. **版权**：不得整段搬运口播；只存自写短摘要 + 链接。  
3. **链接稳定性**：抖音短链 / 分享参数易变；入库应绑 BV 号或 YouTube id。  
4. **夸张与营销话术**：「更离谱」「最火」等属创作者修辞，入库摘要必须降级为「个人表述」。  
5. **时效**：探访为 2025 年公开内容，细节可能已变。
