## 按规范的审核结论

### 能进库吗？

| 选项 | 说明 |
|------|------|
| **A. `limited` 入库（有条件同意）** | 仅 1～2 条**自写摘要** chunk；`answerMode: attributed_claim`；正文强制「据创作者王波粒个人探访视频」；`evidenceLevel: L4`；`status: limited`；主链接用 **B站或 YouTube 稳定 URL**，抖音短链只作 notes；**禁止**存视频全文文稿/OCR 字幕长文 |
| **B. `rejected` / 本轮不入库** | 符合既有 SOURCE_AUDIT_02「L4 本轮不收」精神；仅作选题线索，引导用户去看 L1/L2 |
| **C. 仅作线索，另找上级来源** | 用视频里提到的可核验点（某制度、某门店举措）去官网/权威媒体交叉检索后再入库——**更符合规范 §4 查找顺序** |

**Grok 默认建议：C 优先；若你明确要「体验向」问答素材，则选 A（limited），不要选「当硬事实 approved」。**

### 风险

1. **等级最低（L4）**：协议明确社交不能单独证明争议事实或终局结论。  
2. **版权**：不得整段搬运口播；只存自写短摘要 + 链接。  
3. **链接稳定性**：抖音短链 / 分享参数易变；入库应绑 BV 号或 YouTube id。  
4. **夸张与营销话术**：「更离谱」「最火」等属创作者修辞，入库摘要必须降级为「个人表述」。  
5. **时效**：探访为 2025 年公开内容，细节可能已变。
