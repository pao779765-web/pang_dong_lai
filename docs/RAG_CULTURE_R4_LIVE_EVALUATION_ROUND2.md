## 6. 本轮发现的新系统问题

四题最终返回完全相同的安全降级文本：`R4-C1-01`、`R4-C3-02`、`R4-C4-02`、`R4-C6-01`。其中前三题首轮本来通过，说明 AnswerValidation 在阻止越界的同时产生了新误报。

从当前通用规则可以确定两个高风险点：

- 数字检查尚未区分事实数字、资料日期和 Markdown 列表编号，可能把正常表达当成编造数字；
- 二选一问题的绝对结论检查没有完整识别否定语境，可能把“不能说已经证明”误判成“已经证明”。

此外，当前安全降级对所有可回答问题都使用同一句空泛表述。即便存在经过验证的 Claim，也没有保留“最小可答事实”，因此安全性提高但有用性下降。
