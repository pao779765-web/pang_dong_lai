# RAG 协作任务卡（第一课）

## 当前范围

用户正在学习 RAG 第一课“资料与证据”。本阶段只建立资料标准和候选来源审计流程：

- 不修改 `pangdonglai_project/site/**`；
- 不调用 DeepSeek，也不读取或记录 API Key；
- 不下载、复制或入库新闻全文；
- 不部署、不推送云端。

详细教材见 [`RAG_LESSON_01.md`](./RAG_LESSON_01.md)。

## 分工

| 角色 | 负责内容 | 不负责内容 |
| --- | --- | --- |
| 用户 | 选择候选来源；最终批准哪些内容能进入知识库 | 不需要写代码或复制新闻全文 |
| Codex | 教学、资料卡字段设计；下一课实现本地 RAG-Lite | 不擅自把未核验来源写入知识库 |
| Grok | 对用户提供的最多三条链接做来源审计 | 不改网站代码；不自行扩充来源；不作最终批准 |

## Grok 审计清单

收到用户给出的链接后，逐条检查并在 `docs/SOURCE_AUDIT.md` 写简短结论：

1. 发布主体和来源类型（官方 / 媒体 / 研究 / 其他）；
2. 是否为原始页面或明显的二次转载；
3. 页面可访问性，以及可见的发布日期；
4. 资料能支持的事实，与其中的观点或评价分别是什么；
5. 建议状态：`approved`、`candidate` 或 `rejected`，并说明原因。

未收到用户候选链接前，Grok 不创建资料内容、不写入知识库、不改变 `site/**`。

## 完成条件

第一课完成时，最多三条资料均拥有：标题、原始链接、来源类型、核验日期、短摘要建议和审计状态。只有用户明确同意的 `approved` 条目，才会进入下一课的本地 JSON 资料库。
