## 回答边界（强制）

1. 分阶段：早期回应 → 报告 → 起诉 → 判决（→ 可选社交表述）。  
2. L1 企业材料写「据企业公开…」；检测合格是**报告所载**，非本库复检。  
3. 判决写「据法院/据报道」；名誉权结果 ≠ 监管食安终局 ≠ 医学终局。  
4. 社交材料不得单独支撑质量或侵权结论。  
5. 文化轨只谈流程与表达边界，不裁定真伪。
