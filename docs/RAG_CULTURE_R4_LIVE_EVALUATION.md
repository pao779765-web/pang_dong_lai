## 5. 系统性结论

R4 的热点事件四步已经有效：企业回应、媒体记录、监管与司法结论能被分开，文化观察也没有替代客诉事实判断。

剩余问题主要不在向量召回，而在回答选择与表达约束：

- 一般题不应自动选取某个热点案例；
- 资料不足题必须只说已知、未知和所缺资料；
- 第一段应直接回答，但不能为了“直接”而替用户下单向结论；
- 当前模型频繁逐字显示四个步骤，回答略显模板化。

因此现在接入向量检索反而可能扩大相似案例噪声。应先修复这八题对应的回答边界，复测达到零实质性事实错误、零跨案例噪声和零单向文化裁定，再开始 R5 对照实验。
